One signature. Any token. Exact dollars.

Agents shouldn't need to hold stablecoins to buy data, compute or tools. With Tender, whatever they already hold works as payment.

  1. 1

    The agent signs once

    It asks your API for a price, gets a quote in its own token, and signs one permission that fixes who gets paid and how much.

  2. 2

    Tender swaps it

    In a single transaction the token is swapped to USDG on Uniswap. If the swap comes up short, nothing moves.

  3. 3

    You get exact USDG

    Your API receives the exact price you set, then serves the request. Unused tokens go straight back to the agent.

A few lines on each side.

Put a price on any route of your API. Agents using the Tender client pay automatically, in USDG or in any token with real liquidity on Robinhood Chain.

server.ts
import express from "express";
import { tenderPaywall } from "@paywithtender/sdk";

const app = express();

app.use(tenderPaywall({
  payTo: "0xYourWallet",
  facilitator: "https://facilitator.paywithtender.com",
  routes: {
    "GET /premium": { price: "$0.05" },
  },
}));

app.get("/premium", (req, res) => res.json({ data: "…" }));
import { wrapFetchWithTender } from "@paywithtender/sdk";

const pay = wrapFetchWithTender(fetch, {
  account,                    // the agent's wallet
  chain: robinhood,
  payWith: "0xAnyToken",      // leave out to pay in USDG
  maxUsdgPerCall: 100_000n,   // never more than $0.10
  maxFeePerCall: 20_000n,     // skip if fees top $0.02
});

const res = await pay("https://api.example.com/premium");
// Claude Desktop, Cursor or any MCP client
{
  "mcpServers": {
    "tender": {
      "command": "npx",
      "args": ["-y", "@paywithtender/mcp"],
      "env": {
        "TENDER_PRIVATE_KEY": "0xAgentWalletKey",
        "TENDER_PAY_WITH": "0xAnyToken",
        "TENDER_DAILY_LIMIT_USD": "5"
      }
    }
  }
}

Built so nobody can take more than was signed.

The settlement contract is small, open source and checks every payment before money moves.

Your signature sets the terms

The agent's signature fixes the merchant, the price and the fee. Nobody in the middle can change where the money goes.

Nothing sits in the contract

Tokens pass through in one transaction. The contract holds no balance between payments, so there's nothing to drain.

Short swaps undo themselves

If a swap returns less than the exact price plus fee, the whole payment reverts and the agent keeps its tokens.

Open source

The contract, facilitator and SDK are public. Read them, run your own facilitator, or fork it.
