One rail for every way your API gets paid.

Standard x402, gas covered

Point Coinbase's x402 SDK at Tender and accept USDG with the stock exact scheme. No Tender fee and no code changes.

Any token, exact USDG

Add tender-swap and agents can pay in ETH, $TENDER or any coin with a Uniswap route. You still receive the exact price.

Agents with a wallet

The MCP server gives Claude, Cursor or any MCP client a wallet that pays x402 APIs, with per-call and daily limits.

  1. The agent signs once

    It gets a quote in its own token and signs one permission that fixes who gets paid, how much, and the fee.

  2. Tender swaps it

    In one transaction the token is swapped to USDG on Uniswap. If the swap comes up short, nothing moves.

  3. You get exact USDG

    Your API receives the price you set, then serves the request. Unused tokens go straight back to the agent.

A few lines on each side.

Charge for any route of your API, pay from an agent, or give your AI app a wallet. Every fee is quoted before the agent signs.

Read the quickstart
server.ts
import { x402ResourceServer, paymentMiddleware } from "@x402/express";
import { HTTPFacilitatorClient } from "@x402/core/server";
import { ExactEvmScheme } from "@x402/evm/exact/server";
import { TenderSwapServer } from "@paywithtender/x402";

const server = new x402ResourceServer(
  new HTTPFacilitatorClient({ url: "https://facilitator.paywithtender.com" })
)
  .register("eip155:4663", new ExactEvmScheme())     // USDG
  .register("eip155:4663", new TenderSwapServer());  // any token
import { wrapFetchWithPaymentFromConfig } from "@x402/fetch";
import { TenderSwapClient } from "@paywithtender/x402";

const pay = wrapFetchWithPaymentFromConfig(fetch, {
  schemes: [{
    network: "eip155:4663",
    client: new TenderSwapClient({ account, payWith: "0xTokenYouHold" }),
  }],
});

const res = await pay("https://api.example.com/data");
{
  "mcpServers": {
    "tender": {
      "command": "npx",
      "args": ["-y", "@paywithtender/mcp"],
      "env": {
        "TENDER_PRIVATE_KEY": "0xAgentWalletKey",
        "TENDER_PAY_WITH": "0xAnyToken",
        "TENDER_DAILY_LIMIT_USD": "5"
      }
    }
  }
}

Nobody can take more than was signed.

The signature sets the terms

The agent's signature fixes the merchant, price, fee and resource. Nobody in the middle can redirect the money.

Nothing sits in the contract

Tokens pass through in one transaction. The contract holds no balance between payments.

Short swaps undo themselves

If a swap returns less than the price plus fee, the whole payment reverts and the agent keeps its tokens.

Open source

Contract, facilitator and SDKs are public, and the contract is verified on Blockscout. No external audit yet, so payment sizes are capped.
